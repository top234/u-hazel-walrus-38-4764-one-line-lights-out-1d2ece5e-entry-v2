Entry for the [One Line, Lights Out](https://make.fun/bounty/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty on make.fun.

The program writes a single status update — under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

`OUTPUT_DIR` overrides the output directory (default `/output`).
